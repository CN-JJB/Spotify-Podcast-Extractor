From a podcast to your notes

Save an episode’s existing Spotify transcript in the format you use. No extension account, audio upload or transcription service is needed.

Export an episode

  1. Open a podcast episode on Spotify’s web player. Sign in to Spotify if the page asks you to.
  2. Check that the episode has a Transcript tab.
  3. Click the browser’s extensions button, then Spotify-Podcast-Extractor. Pin it for easy access.
  4. Keep the episode tab open while the export tab reads the transcript. Review its first and last lines, sentence count and full preview.
  5. Choose Markdown, TXT, HTML, JSON or CSV, then click Download. Your browser saves the file.

Use with Obsidian

Choose Markdown and keep speaker labels enabled. Save the file to your Obsidian vault. Speaker turns appear in separate callout blocks: Speaker 1 is blue and Speaker 2 is green. The extension labels missing speaker information instead of guessing a name.

If a transcript cannot be read

Make sure you are on an episode page, not a show page, and that Spotify provides a transcript. Wait for it to finish loading, then click the extension again. If Spotify changes its page structure, the extension may stop rather than export text it cannot verify. Report an issue at GitHub Issues with the extension version and error message. Do not post private transcripts or account information.

Only text available in the current transcript panel is exported. This is not speech recognition, an audio downloader, translation, or a guarantee of the platform’s transcription accuracy. SRT and VTT are not generated when sentence timestamps are unavailable.

The language selector changes the interface and export headings, not the original transcript. JSON and CSV preserve sentence records; their content does not depend on the text-layout checkboxes.

把播客原文带进笔记

导出 Spotify 已提供的转录。不需要注册扩展账号、上传音频或配置转写服务。

导出一集

  1. 在 Spotify 网页版打开播客单集；如果 Spotify 要求登录，按网站提示登录。
  2. 确认这集有「转录」标签。
  3. 点击浏览器右上角的扩展按钮，选择「Spotify-Podcast-Extractor」。可点图钉固定到工具栏。
  4. 读取时保留原单集标签页。核对首句、末句、句数，也可以展开全文预览。
  5. 选择 Markdown、TXT、HTML、JSON 或 CSV，点击「下载」，由浏览器保存文件。

在 Obsidian 中使用

选择 Markdown，勾选「保留说话人」，保存到笔记仓库。每次说话人切换会形成独立彩色引用块：Speaker 1 蓝色，Speaker 2 绿色。页面没有标明身份时，显示「未标注说话人」，不会猜测人名。

读取失败时

确认打开的是单集页面而非节目主页，并且该集提供了转录。等待页面加载完，再点击扩展。Spotify 页面结构变化时，扩展可能停止导出；可通过 GitHub Issues 反馈版本号和错误提示；不要公开私人文字稿或账号信息。

仅导出当前转录面板已有内容，不做语音识别、音频下载或翻译，也不保证原始转录的准确性。没有逐句时间码时，不生成 SRT / VTT。

语言切换只影响界面和导出标题，原文不翻译。JSON、CSV 保留逐句记录，不受文字排版复选框影响。
