# Spotify-Podcast-Extractor 产品设计

目标是让已有 Spotify 转录变成可检查、可保存、可在笔记中继续使用的原文。首版按免费、中英双语、无扩展账号准备；用户已确认免费、中英双语方向。Chrome 网上应用店尚未发布。

## 面向谁

主要服务听英文播客做笔记的学习者，其次是使用 Obsidian 整理访谈和播客资料的人。核心任务是打开一集、确认文字完整、保存带说话人的笔记。

## 用户为什么选择它

1. 读取已加载转录节点，避免屏幕外文字被可见文本提取漏掉。
2. 导出前展示句数、首句、末句和全文预览，让用户能核对。
3. Markdown 中每次说话人切换都是独立彩色引用块；原文不改写。
4. 一份转录可下载为 Markdown、TXT、HTML、JSON 或 CSV。
5. 内容在本机处理，不上传到转写服务，不需要扩展账号或 API Key。

“完整”只表示当前单集转录面板已有的内容；不宣传“所有节目都支持”“100% 准确”“永久免费保证”或虚构的使用人数。

## 首版体验

进入 Spotify 单集 → 点击扩展 → 独立导出页读取 → 检查首尾与说话人 → 选择格式 → 浏览器保存文件。

默认 Markdown，默认保留说话人与来源。保留用户认可的浅色阅读界面；蓝色与绿色用于不同说话人，标题文字也明确标识，颜色不是唯一线索。界面支持中文与英文，语言选择不翻译原始转录。

错误时不交付可疑的半篇内容：区分没有转录、仍在加载、页面切换、访问失效、结构不支持。提供下一步操作，并保留重试入口。

帮助与隐私在扩展内可离线查看。公开商店截图使用原创演示文字，注明 Demo，展示实际界面，不包含用户账号或第三方完整文字稿。

## 首版范围

没有真实逐句时间码时不生成 SRT/VTT。先把当前任务做可靠，再决定是否扩展平台。

## 名称和视觉

用户确认产品名：**Spotify-Podcast-Extractor**，与 GitHub 仓库同名。扩展是该开源项目的 Chrome 产品，MIT 许可，界面附 GitHub 源码入口。独立的对话框和下载文档图标，不使用 Spotify 标志、Obsidian 标志或“官方”措辞。商店及帮助页明确说明独立关系。

图标规格：16、32、48、128 像素；商店图标 128 像素。截图 1280×800。额外提供 440×280 宣传图。素材依据 [Chrome 官方图片要求](https://developer.chrome.com/docs/webstore/images) 制作。

## 发布与反馈

建议先以 Unlisted 提交，通过商店链接给少量用户体验，再决定公开展示。Unlisted 仍需完整审核，不是绕过审核的方式。[官方分发说明](https://developer.chrome.com/docs/webstore/cws-dashboard-distribution)

首版不安装分析 SDK。先从用户自愿反馈中记录：是否成功导出、失败类型、格式使用需求和兼容性问题。反馈不默认收集文字稿；浏览器语言、长节目、无转录、不同说话人结构是继续扩测的重点。

收费功能会引入额外账号、付款与支持责任，先作为后续决策，不加入首版。
