名称
Spotify-Podcast-Extractor

简短说明
将 Spotify 已有的播客转录导出为 Markdown、TXT、HTML、JSON 或 CSV，保留说话人标签，在本机处理。

详细说明
把播客对话带进你的笔记。

Spotify-Podcast-Extractor 读取 Spotify 单集页面已有的转录。导出前可以核对原文、首句和末句，再通过浏览器保存文件。

• 五种格式：Markdown、纯文本、离线阅读网页、JSON 和 CSV。
• 适合 Obsidian：每次说话人切换形成独立引用块；Speaker 1 蓝色、Speaker 2 绿色，文字标签清晰区分。未标明身份的段落如实标注，不猜测人名。
• 导出前核对：显示句数、正文字符数、首句、末句和完整预览。
• 读取屏幕外字幕节点，保留重复句和原始措辞，下载不设置文字长度上限。
• 中文与英文界面，切换界面语言不会翻译原文。
• 本机处理，不需要扩展账号或 API Key，没有统计上报，不上传文字稿。
• 免费、MIT 开源，扩展内可直接打开 GitHub 源码和反馈入口。

使用方法
1. 在 Spotify 网页版打开有「转录」标签的播客单集。
2. 点击扩展图标，读取过程中保留原单集标签页。
3. 核对文字，选择导出格式。
4. 点击下载，由浏览器保存文件。

支持范围
仅导出当前转录面板已提供的内容，不做语音识别、音频下载或翻译，不保证 Spotify 原始转录的准确性。部分单集、账号或地区可能没有转录。面板仍在变化或结构不支持时，会提示原因，不将无法确认的部分文字标成完整导出。没有逐句时间码时，不生成 SRT / VTT。

权限用途
activeTab 与 scripting 用于你主动点击后读取所选单集；downloads 用于保存和监测本次下载。转录正文和单集网址在你的设备上处理，不发送给开发者或第三方服务。
