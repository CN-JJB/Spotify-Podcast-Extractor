# Chrome 网上应用店审核与隐私填写

对应扩展版本 1.1.0。按实际功能填写，不因为“本机处理”就填写“不处理任何数据”。以下判断依据 [官方用户数据 FAQ](https://developer.chrome.com/docs/webstore/program-policies/user-data-faq) 和 [Privacy practices 填写说明](https://developer.chrome.com/docs/webstore/cws-dashboard-privacy)；后台字段若有变化，以提交时实际定义核对。

## Single purpose description

Export the transcript already available on a user-selected Spotify podcast episode into a downloadable Markdown, TXT, HTML, JSON or CSV file, preserving its original text and available speaker labels.

## Permission justifications

| Permission | 可直接填写的英文说明 |
| --- | --- |
| activeTab | Grants temporary access to the episode tab only after the user clicks the extension action. The extension reads that selected episode's title, podcast metadata, URL and transcript for the requested export. It does not request persistent host access or inspect unrelated tabs. |
| scripting | Runs the bundled extractor in the user-selected Spotify episode tab to open the Transcript panel, read all available transcript text nodes, check loading stability and restore the page's scroll position. No remote code is fetched or executed. |
| downloads | Saves a locally generated Blob in the user's chosen format through the browser download manager. It monitors only downloads it initiates and checks those download IDs for completion; it does not search or scan the user's download history. |

## Remote code

选择 **No / 不使用远程代码**。所有 JavaScript、样式、图标随扩展打包。没有远端执行、动态代码下载、eval 或外部字体。GitHub、Spotify 链接是用户主动打开的普通链接。

## Data usage

- **Website content / 网站内容：披露。** 单集标题、节目名、转录正文、说话人、章节和页面提示。
- **Web history / 网页历史：按“所选页面 URL”披露。** 仅处理用户主动选择的当前单集网址及节目链接，用于来源标注；不遍历或存储浏览历史。这里是对后台 URL 分类的保守对应，并不意味着扩展取得了 `history` 权限。
- 不处理身份、健康、财务、认证凭据、个人通信或位置数据；没有点击追踪分析。
- 开发者与第三方接收：无自动上传。文字只在当前导出标签页内存和用户主动下载的文件中。
- 不出售数据；不为单一用途以外的目的使用或转移数据；不用于信用或借贷决策。依照这些实际事实确认后台的相关承诺。

## Test instructions — reviewer notes

The extension has no account system, subscription or API key. Use Spotify's web player and sign in to Spotify if Spotify requires it. No developer credentials are required by this extension.

1. Open a Spotify podcast episode that currently exposes a Transcript tab. One episode used for local compatibility testing was https://open.spotify.com/episode/4plcEhWktibRjHu9YvV54t . Transcript availability is controlled by Spotify and may vary by account, region or time; use another episode with a visible Transcript tab if necessary.
2. Click the extension's toolbar action while the episode tab is selected. This action grants activeTab access; directly opening export.html or reusing its URL is not the correct entry point.
3. Keep the source episode open without changing episodes. A new export tab shows the title, sentence count, first and last sentence, and the expandable transcript preview.
4. Select Markdown and Download. Verify that speaker turns use labeled Obsidian callouts. Try TXT, HTML, JSON and CSV from the same tab. The browser's save-location dialog is enabled by default and can be disabled in the UI.
5. Switch the interface between English and Chinese. Original transcript wording remains unchanged. Open Help, Privacy and GitHub from the header.
6. On an episode without a transcript, the extension displays an explanatory error and disables download. Unsupported or unstable transcript structure also produces an error instead of a potentially incomplete export.

The store screenshots use original demonstration text in a local test fixture. The demo is not a published Spotify episode and is not represented as a real show. Test tools grant an origin permission only to a disposable test copy for headless automation. The uploaded release ZIP contains only activeTab, scripting and downloads, with no host_permissions.
