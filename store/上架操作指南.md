# Spotify-Podcast-Extractor 上架操作指南

产品已确认：免费、中英双语，Chrome 扩展是同名 MIT 开源项目的衍生产品。**代码发布到 GitHub，不等于已经上架 Chrome 网上应用店。** 商店仍需开发者账户、资料填写与审核。

## 1. 开发者账户准备

使用长期保留的 Google 账号进入 [Chrome Web Store 开发者后台](https://chrome.google.com/webstore/devconsole)。按页面完成开发者注册、一次性登记费用和条款确认，金额以实际页面为准。为 Google 账号启用两步验证；后台填写开发者显示名并验证联系邮箱。[官方注册说明](https://developer.chrome.com/docs/webstore/register)、[账户资料](https://developer.chrome.com/docs/webstore/set-up-account)、[两步验证要求](https://developer.chrome.com/docs/webstore/program-policies/two-step-verification)

可使用公开 GitHub 身份 `CN-JJB` 作为开发者显示名，最终以你填写的身份为准。支持入口已有 GitHub Issues；后台联系邮箱仍需你提供并完成验证，不从其他账号资料擅自推断。

## 2. 上传正确的 ZIP

新建项目，上传 `dist/Spotify-Podcast-Extractor-1.1.0-webstore.zip`。

这个 ZIP 的最外层直接包含 `manifest.json`，只含发布所需的扩展文件。不要上传整个 GitHub 源码 ZIP、发布资料包或 manual ZIP。官方要求 manifest 在 ZIP 根目录。[打包要求](https://developer.chrome.com/docs/webstore/prepare)

`dist/Spotify-Podcast-Extractor-1.1.0-manual.zip` 用于审核前手工试用：解压后，在 `chrome://extensions` 开启开发者模式，加载里面直接包含 manifest 的 `Spotify-Podcast-Extractor` 文件夹。

## 4. 隐私与审核说明

按 `store/审核与隐私填写.md` 填写：单一用途、三项权限用途、没有远程代码、处理的网页内容及所选网址、仅本机处理，以及测试步骤。公开隐私链接在代码推送到 main 后可用；提交前用未登录窗口确认能够打开。

本机处理也属于处理用户数据，不能简单选择“完全不处理数据”。这来自 Chrome 的 [用户数据 FAQ](https://developer.chrome.com/docs/webstore/program-policies/user-data-faq)。

## 5. 分发、审核与发布

建议首次选择 **Unlisted（不公开列出）**，通过商店链接给少量用户试用。它仍然需要审核，拿到链接的人可以访问；不要当作私密访问控制。需要公开搜索发现时再改为 Public。[分发说明](https://developer.chrome.com/docs/webstore/cws-dashboard-distribution)

确认资料后提交审核。若后台提供审核通过后自动发布与手动发布选项，初次建议手动发布，先复查商店页；按后台所示期限完成发布。审核通过时间不作保证。[发布流程](https://developer.chrome.com/docs/webstore/publish)

获得商店链接后，把链接补到根 README 的安装区，并更新 `store/release-settings.json` 的发布状态。后续更新保留同一商店项目、提高扩展版本号，再上传新 ZIP。
